# Third-party GUI assets

The GUI includes two optional background files supplied directly by the
project owner for this non-commercial Deltarune controller:

- `deltarune_agent/qt_ui/assets/backgrounds/epic_wallpaper.mp4`
  - SHA-256: `d0f73f3ed27d087f2a28325c139d7a949a020243c7d81052c009821e9c59fe3a`
- `deltarune_agent/qt_ui/assets/backgrounds/second_wallpaper.gif`
  - SHA-256: `d7725c590808cad3f4d9eeb18a2d86fbe3563d991cfd691152d05cf37ba23b94`

The original artist and download page were not embedded in the supplied
files and were not provided with them. This repository does not claim
ownership of the artwork. Deltarune and its characters belong to their
respective rights holders. If the original source becomes known, add the
artist and source URL here before redistributing the backgrounds further.

Both files are cosmetic. The artwork-free Operator theme remains available,
and deleting either file must not prevent the controller from starting.
